# FlowTrace

**A hardware-aware CFD solver and warm-start companion for Ansys Fluent.**

FlowTrace solves incompressible flow (steady and transient), heat transfer, RANS turbulence and,
with a density-based solver, compressible flow on structured and unstructured meshes. It measures the CPU and GPU of the machine it runs on and puts each stage
of the solve where it is fastest. It also reads and writes the files Ansys Fluent uses (`.msh`,
`.cas.h5`, `.dat.h5`, `.ip`, `.prof`, journals, PyFluent scripts).

Its main purpose is to **produce a good initial field quickly**, which Fluent then interpolates
and continues from (a *warm start*), with evidence that the field is right:

* **Verified:** manufactured solutions show second-order convergence for both pressure-based
  solvers (pressure on triangles: order 1.2). The grid convergence index is reported for key
  quantities. Every SIMPLE/SIMPLEC run also reports [algebraic diagnostics](theory/diagnostics.md):
  how far each linear system and the continuity constraint actually got.
* **Validated:** results are compared with published data (Ghia et al., de Vahl Davis, the
  Moser–Kim–Mansour DNS, White's flat-plate correlation, Driver & Seegmiller). The comparisons
  come with acceptance criteria and are regenerated by `flowtrace benchmark`. Every number in
  the [validation report](validation/index.md) comes from that command.
* **Honest about limits:** see [what FlowTrace does not do](#limits).

## Thirty-second tour

```bash
pip install "flowtrace[cpu,amg,h5,report]"
flowtrace probe                                # what FlowTrace sees on this machine
flowtrace run cavity --re 1000 --n 256         # structured solver, planner picks CPU/GPU
flowtrace fluent-warmstart my_case.cas.h5 --turbulence k-omega-sst --out ws/
flowtrace benchmark --tier quick               # re-run the verification suite yourself
flowtrace                                      # dashboard at http://127.0.0.1:8765
```

## What is inside

| Area | Capabilities |
|---|---|
| Structured solver | 2-D incompressible Navier–Stokes + Boussinesq energy on a MAC grid, exact pressure projection, QUICK/TVD, AB2/Crank–Nicolson, immersed obstacles, FMG |
| Unstructured solver | Fluent-style pressure-based SIMPLE/SIMPLEC on any cell shape (2-D/3-D), Rhie–Chow, AMG pressure correction; steady or transient (Euler/BDF2); P-1 radiation; passive species |
| Compressible solver | Density-based: HLLC + MUSCL, implicit steady or SSP-RK3, Euler / Navier–Stokes / k-ω SST, 2-D, 3-D polyhedral, axisymmetric |
| Turbulence | k-ω SST (Menter 2003, y⁺-insensitive), realizable and standard k-ε with scalable wall functions (Fluent's κ = 0.4187, E = 9.793) |
| Zones | Conjugate heat transfer (solid zones), moving reference frames, rotating walls, translational periodicity |
| Fluent files | `.msh`/`.cas` (ASCII/binary/gzip), CFF `.cas.h5`/`.msh.h5`/`.dat.h5`, `.ip`, `.prof`, journals, PyFluent |
| Hardware | CPU (NumPy, Numba JIT, C++/OpenMP kernels), NVIDIA GPU (CuPy + fused CUDA kernels); measured placement; FP64 unless FP32 is shown to meet the case's tolerance |
| Quality | Mesh quality report with Fluent-style orthogonal quality, skewness (standard element shapes) and aspect ratio |

## Limits { #limits }

* The compressible solver is verified on canonical cases (Sod, oblique shock, flat plate) but
  not yet compared with Fluent, and its CUDA kernel has not run on a GPU
  ([what is not validated](theory/compressible.md#not-yet-validated)).
* RANS only (steady or unsteady). No LES/DES, multiphase, combustion or moving/deforming meshes;
  radiation is P-1 only.
* The structured solver is 2-D. The unstructured solver handles 3-D, but it is written in Python
  (vectorised NumPy/CuPy), so very large 3-D cases are slower than in a compiled commercial code.
* The Fluent readers are [checked against files written by Fluent](user-guide/fluent.md#checked-against-files-written-by-fluent),
  and the writers reproduce Fluent's face-by-face layout, but no file written by FlowTrace has
  been read back into Fluent yet (that needs a licence).
* The Fluent side of the warm-start study needs a Fluent licence. Until it has been run, its
  table contains labelled placeholders, never estimated numbers.
